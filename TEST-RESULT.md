# Verification Record — v0.15.0

`npm test` passed with 174 tests and no failures in the source tree (162 pre-existing tests plus 12 new lineage/schema tests). Every JavaScript module under `src/` and the new test files passed `node --check`; `npm start` completed and printed the v0.1–v0.14 example output followed by the new v0.15 schema-validation, lineage, and relationship sections against the loaded CSV. `git diff --check` reported no whitespace errors.

The v0.15.0 regressions cover the roadmap's exact `validateSchema` example shape (string/number/date types with required and nullable flags) passing cleanly, typed error reporting (missing required columns as `MISSING_COLUMN` errors vs warnings for optional columns, `NOT_UNIQUE` for duplicate unique values, `NULL_NOT_ALLOWED` for nulls in non-nullable columns, `TYPE_MISMATCH` for cast failures, `CONSTRAINT_VIOLATION` for enum and custom constraint failures), min/max/minLength/maxLength/pattern/enum/custom constraints with correct row attribution, shorthand type-string rules, `toJSON()`/`createSchema()` round-trips with internal bookkeeping excluded, `isValid`/`validationReport`/`assertSchema` on both `Dataset` and `AnalysisResult` (including derived results with no definition), lineage accuracy (source name, operation chain, recorded where-conditions), lineage immutability under mutation attempts, propagation through derived results, absence of dataset row copies in lineage objects, relationship definitions across all four cardinalities with duplicate primary/foreign-key and orphaned foreign-key detection and missing-column reports, relationship-name/reference validation, joins remaining possible without any relationship definitions, collection add/get/has/names/size behavior with duplicate-name and unknown-reference rejection, and the continued Dataset/AnalysisResult distinction through the new validation surface.

Schema validation, relationships, and collections are exported from the package root and `numeriq/schema` / `numeriq/collection` subpaths, with TypeScript declarations in `index.d.ts`. The v0.16.0 visualization-engine milestone is deferred as documented in the README roadmap.
