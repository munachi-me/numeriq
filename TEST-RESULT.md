# Verification Record — v0.12.0

`npm test` passed with 138 tests and no failures in the source tree (114 pre-existing tests plus 24 new join tests). Every JavaScript module under `src/` and the new test files passed `node --check`; `npm start` completed and printed the v0.1–v0.11 example output followed by the new v0.12 join sections. `git diff --check` reported no whitespace errors.

The v0.12.0 regressions cover every join type (inner, left, right, full, cross) with row-level output assertions, the unified `join()` method matching each dedicated method, multiple shared keys (`on: ['customerId', 'region']`), differently named keys single and multiple (`leftOn`/`rightOn`), collision suffixes including the exact `['_sales', '_customers']` roadmap example, shared-key single appearance and right-only key dropping, one-to-one/one-to-many/many-to-one/many-to-many validation with duplicate keys on the correct offending side, null join keys never matching (including null-to-null) while being preserved on outer joins, unmatched left/right rows with null-filled opposite-side columns, duplicate keys multiplying matched rows (2×2 → 4 with all combinations), empty inputs for every join type, join results composing into `analyze()`/`groupBy()`/`filter()`/`select()` chains, AnalysisResult and plain-array inputs, input immutability, join-aware lineage (`join:left`), explicit error messages for unsupported join types, unknown keys on either side, mixed on/leftOn forms, mismatched leftOn/rightOn counts, duplicate keys within a side, invalid suffix arrays, invalid relationships, unknown options, cross-join key rejection, and null right inputs, plus early rejection of suffix targets that already exist in the output. Join execution uses hash indexes; matched rows preserve left (inner/left/full) or right (right) source order with unmatched rows appended in source order.

A v0.11.0 regression was found and fixed during v0.12.0 development: `AnalysisResult.analyze()` failed with a ReferenceError (missing `AnalysisBuilder` import) and is now covered by a dedicated regression test. Join methods are declared for `Dataset` and `AnalysisResult` in `index.d.ts`. The v0.13.0 window-function milestone is deferred as documented in the README roadmap.
