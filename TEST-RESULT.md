# Verification Record — v0.11.0

`npm test` passed with 114 tests and no failures in the source tree (97 pre-existing tests plus 17 new analysis-engine tests). Every JavaScript module under `src/` and the new test file passed `node --check`; `npm start` completed and printed the v0.1–v0.10 example output followed by the new v0.11 fluent-analysis, conditional-aggregation, global-summary, lineage, and scalar-preservation sections. `git diff --check` reported no whitespace errors.

The v0.11.0 regressions cover the fluent `analyze()` builder (groupBy, sum/mean/count with `as` aliases, orderBy, having, limit, offset, where, distinct), direct chaining with aggregation helpers on both `Dataset` (returns a `Dataset`, preserving v0.5.0 behavior) and `AnalysisResult` (returns an `AnalysisResult`), global aggregation without `groupBy()`, the full aggregation catalog including `average`/`stddev` aliases, `percentile`, and `quartiles` with `ddof`/`q`/`p`/`method` options, conditional aggregations via `where`, AnalysisResult surface completeness and the deliberate absence of Dataset-specific members (`profile`, `importReport`, `describe`, `info`, `metadata`, `name`), immutability of every operation, empty datasets, null handling, table output (1000-row default, custom and `Infinity` maxRows, `Showing X of Y rows.` footers for full/empty data, invalid maxRows rejection), default and named export parity, analysis-document serialization and replay (`toJSON()`/`fromJSON()` with function-predicate rejection), lineage tracking across derived results, and consistent error messages for unknown columns, duplicate keys, and misplaced `groupBy()` calls. Legacy `GroupedDataset` default column naming (`count of rows`, `sum of n`, `mean of n`) and global groupBy behavior are covered unchanged.

Scalar methods (`sales.sum('amount')`, `sales.mean('amount')`, `sales.min('amount')`, `sales.max('amount')`) retain scalar return types. The v0.12.0 join engine is deferred as documented in the README roadmap; the shared result-factory architecture is prepared for it.
